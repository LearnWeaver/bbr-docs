Latching a colour trigger#

BBR Expander Latching Example — a colour trigger in LATCHED mode holding a digital output high after the colour has gone.

A sensor port is taught a colour and a digital output is set to LATCHED mode, so the output goes high the moment that colour is seen and stays high after the colour has passed. The pin is only cleared when the code asks for it with clearOutputLatch().

That is the difference worth watching for: the colour is present for a fraction of a second, far too briefly for a loop to be guaranteed to catch it, and the output still comes on and stays on. See Latching for the code.
